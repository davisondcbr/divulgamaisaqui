① Instalar o mesmo APK em qualquer TV Box compatível

④ Informar conexão e reprodução ao servidor

VERIFICANDO...

Verificando automaticamente a resposta da API...

O painel continuará no modo local até configurarmos autenticação, políticas de acesso (RLS) e sincronização. A chave pública configurada neste HTML ficará visível no código hospedado no GitHub (isto é esperado para a Publishable Key). A URL /rest/v1/ é um endpoint e não é uma Publishable Key.

Painel integrado ao Supabase.

Após login, os cadastros são sincronizados com o Supabase. Os arquivos enviados são armazenados no bucket público anuncios. O acesso aos arquivos é público para permitir reprodução nas TVs.

Próximas etapas: autenticação, banco de dados, armazenamento de mídia, ativação segura dos dispositivos, status online real, histórico de exibições e APK Android com modo quiosque. Nunca coloque senhas de administrador ou chaves privadas neste HTML público.
