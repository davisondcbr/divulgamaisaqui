# DIVULGA+AQUI — Admin

Esta pasta é independente do index.html principal do site.

- admin/index.html — entrada do painel administrativo.

Ao enviar a pasta admin para a raiz do repositório, o GitHub Pages poderá servir o painel em /admin/.

Observação: este pacote cria a área separada do painel. Para restaurar o painel administrativo antigo completo, será necessário inserir nesta pasta os arquivos/código daquele painel.
