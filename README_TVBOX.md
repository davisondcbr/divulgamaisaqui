# DIVULGAMAISAQUI TV Box Compatível

Versão preparada para TV Boxes econômicas e antigas.

- Android mínimo: 5.1 (API 22)
- Target SDK: 28
- Sem exigência de touchscreen
- Leanback opcional
- Mantém player web: https://davisondcbr.github.io/divulgamaisaqui/tv.html
- Inicialização no boot mantida
- Modo imersivo/kiosk mantido quando permitido pelo dispositivo

## Gerar APK
Envie estes arquivos para a raiz do repositório GitHub e execute a Action `Gerar APK DIVULGAMAISAQUI`. O artefato gerado se chama DIVULGAMAISAQUI-APK.
